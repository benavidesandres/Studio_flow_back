Qué decir (50 s). Este es el nivel 2 del C4. Un navegador con la aplicación React llama a una única API de Spring Boot. Dentro hay tres módulos. Planificación le pregunta a Reparto si todos los citados son actores, por un contrato Java, no por red. Cuando programa una escena publica el evento EscenaProgramada y Presupuesto lo consume dentro de la misma transacción. Todo termina en una base PostgreSQL con tablas prefijadas por módulo y sin claves foráneas entre módulos. Importante: es un solo proceso. No decimos microservicios porque no lo son. El esqueleto implementa la API con sus tres módulos; usa H2 en vez de Supabase y una página de demostración en vez de React.
