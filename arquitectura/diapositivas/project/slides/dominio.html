El dominio

Planificar un rodaje exige reglas que no se improvisan

Reglas de negocio

  • Dos escenas solapadas con el mismo actor se rechazan
  • Menos de 45 min entre locaciones: advertencia aceptada de forma explícita
  • Cada escena compromete presupuesto

Cuatro usuarios

  • Productor: producciones y presupuesto
  • Director: programa y resuelve conflictos
  • Equipo técnico: consulta el llamado
  • Actor: solo su agenda

Restricciones externas

  • Ley 1098 de 2006, art. 35: menores de 15 años
  • Ley 1581 de 2012: datos personales
  • PostgreSQL gestionado en Supabase
  • Locaciones con red intermitente

Qué decir (45 s). StudioFlow no es un CRUD: tiene reglas. Un actor no puede estar en dos escenas que se solapen, ni siquiera de producciones distintas. Si el traslado entre locaciones es menor a 45 minutos, el sistema advierte y solo guarda si el director lo acepta. Hay cuatro tipos de usuario con permisos distintos, y restricciones externas reales: la Ley 1098 sobre menores artistas, la Ley 1581 de datos personales, Supabase como base y rodajes sin buena conexión.
